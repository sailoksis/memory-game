# Memory Game

Memory Game is a card matching game built with vanilla JavaScript.

The game contains 16 cards forming 8 matching pairs. The goal is to find all pairs in as few moves as possible.

## Features

- Random card shuffle on every new game
- Move and matched-pair counters
- Card matching logic with a delay for mismatched pairs
- New Game functionality
- Victory modal with the final number of moves
- Top 10 leaderboard
- Results saved in localStorage
- Responsive layout

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/sailoksis/memory-game.git
   ```

2. Go to the project directory:

   ```bash
   cd memory-game
   ```

3. Switch to the development branch:

   ```bash
   git checkout memory-game
   ```

4. Open `index.html` in your browser.
